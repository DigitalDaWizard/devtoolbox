# DevToolbox

A tiny, zero-dependency browser toolkit for developers.

## Tools
- JSON formatter / minifier
- Base64 & URL encode/decode
- SHA-256 hash (Web Crypto)
- UUID v4 generator
- Color converter (HEX / RGB / HSL)
- Unix timestamp converter
- Live regex tester
- Case converter
- Text statistics

## Use it
Open `index.html` in a browser, or visit the live GitHub Pages site:
https://DigitalDaWizard.github.io/devtoolbox/

## Run locally
Just open `index.html` — that's it. No build step.

## Why it exists
DevToolbox is meant to be a small, fast, dependency-free companion for everyday dev tasks. It stays lightweight, runs in any browser, and does not require npm, bundlers, or a server.
